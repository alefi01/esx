# Готовый виджет для рабочего стола

`portal-widget.exe` — собранная программа, которую администратор кладёт
на портал. Один файл: на рабочих ПК ничего ставить не нужно.

**Как попадает на портал:** файл кладётся в папку `App_Data\client`
рядом с сайтом. После этого в настройках портала появляется рабочая
кнопка «Скачать виджет для ПК», и портал сам дописывает в конец файла
свой адрес — скачавший не вводит его руками.

**Что требуется на рабочем ПК:** компонент Microsoft Edge WebView2
Runtime. Если его нет, виджет при установке покажет окно с объяснением
и кнопкой «Скачать с портала и установить» — установщик компонента
берётся с портала, из той же папки `App_Data\client` (файл
`MicrosoftEdgeWebView2RuntimeInstallerX64.exe`). Интернет на рабочем ПК
не нужен.

**Если виджет не запускается:** он пишет журнал в
`%LOCALAPPDATA%\PortalWidget\widget.log` (а если профиль недоступен —
в `%TEMP%\portal-widget.log`). Подробности — в
`docs/14-этап-10-отделы-задачи-виджет.md`, раздел «Если виджет
не запускается».

**Как собран:** `dotnet publish src/Portal.Client -c Release`. Один файл,
со встроенным .NET и сжатием — около 50 МБ. Исходники лежат
в `src/Portal.Client`, и пересобрать можно в любой момент: этот файл
здесь только ради того, чтобы не собирать его на машине администратора.
