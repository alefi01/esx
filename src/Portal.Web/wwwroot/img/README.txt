Картинки портала
================

Папка нужна для того, что кладёт администратор. В поставке портала
картинок нет вовсе: значки нарисованы кодом (Pages/Shared/_Icons.cshtml),
значок вкладки браузера рисует сам портал по названию и фирменному цвету
из секции Branding.

  logo.svg (или logo.png)
      Свой логотип организации. Чтобы портал начал его показывать,
      пропишите путь в appsettings.json:

          "Branding": { "LogoFile": "/img/logo.svg" }

      Этот же файл станет значком вкладки браузера.

  themes\
      Картинки-фоны рабочего пространства. См. themes\README.txt.
